# Electoral Reservation Measurement Study v0.1.0

First public working-paper and reproducibility release.

## DOI

- Version 0.1.0: [10.5281/zenodo.21591947](https://doi.org/10.5281/zenodo.21591947)
- All versions: [10.5281/zenodo.21591946](https://doi.org/10.5281/zenodo.21591946)

## Highlights

- Corrects constituency vote-share denominators to use every valid candidate
  vote record before restricting the gender-analysis sample.
- Uses a leave-one-out 2004 party-state baseline and excludes singleton groups.
- Treats missing education with median imputation and an explicit missingness
  indicator rather than coding it as illiteracy.
- Refreshes the core results and manuscript consistency audit.
- Corrects historical representation figures and limits nomination-stage claims
  to what the observed candidacy data support.
- Provides self-contained arXiv and Zenodo submission packages.
- Adds tracked data provenance, input checksums, deterministic release tooling,
  citation metadata, and an MIT code license.

## Main corrected estimate

The corrected primary matched sample contains 7,639 observations. The
full-control female coefficient is -0.60 percentage points (HC3 SE 0.40,
p = 0.14).

## Important limitations

This is a descriptive measurement and validation study, not a causal estimate
of nomination discrimination or candidate capability. Journal submission still
requires stronger dependence-robust uncertainty, full-suite reruns from the
corrected specification, and additional convergent validation.

The release archives do not relicense third-party election data. Users must
follow the original data providers' terms.
