# Zenodo Submission Checklist

- [x] Prepare the working-paper PDF.
- [x] Prepare the self-contained LaTeX source ZIP.
- [x] Prepare a replication archive that excludes raw data.
- [x] Generate SHA-256 checksums.
- [x] Prepare `publication` / `workingpaper` metadata.
- [ ] Sign in to Zenodo and create a new upload.
- [ ] Optionally reserve the DOI before publication.
- [ ] Upload the files from `zenodo/` individually.
- [ ] Add ORCID and affiliation if applicable.
- [ ] Choose the manuscript license after checking intended journal policies.
- [ ] Preview the public record and every uploaded file.
- [ ] Publish the record.
- [ ] Add the assigned DOI to the README, paper, and citation metadata.

The deposit must not include compressed TCPD or other third-party raw election
datasets unless their redistribution terms have been independently confirmed.
