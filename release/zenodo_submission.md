# Zenodo Submission Checklist

- [x] Prepare the working-paper PDF.
- [x] Prepare the self-contained LaTeX source ZIP.
- [x] Prepare a replication archive that excludes raw data.
- [x] Generate SHA-256 checksums.
- [x] Prepare `publication` / `workingpaper` metadata.
- [x] Sign in to Zenodo and create a new upload.
- [x] Reserve or assign the DOI.
- [x] Upload the files from `zenodo/`.
- [ ] Add ORCID and affiliation if applicable.
- [ ] Choose the manuscript license after checking intended journal policies.
- [x] Preview the public record and uploaded files.
- [x] Publish the record.
- [x] Add the assigned DOI to the README, paper, and citation metadata.
